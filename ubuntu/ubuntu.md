# Ubuntu

Package manager on the studio VM (`apt`). Generic shell commands stay in [linux.md](../linux/linux.md).

---

## Update package list

```terminal
$ sudo apt update
```

## Install a package

```terminal
$ sudo apt install <package>
$ sudo apt install unzip
$ sudo apt install curl
$ sudo apt install neovim
```

`nvim --version` checks the install. `nvim` is the binary.
